# Example Scene

*Not built yet — this lands in Phase 6.*

This directory will hold a small, polished scene built from the starter template plus 3-5 asset-kit items, demonstrating a clear mood or theme. It's what facilitators open at minute zero as "here's what you'll build toward," then view-source live on the projector to make the point that the whole thing is a readable amount of HTML.

The constraint on this scene: it must be built **entirely from documented asset-kit items and starter-template primitives**. Nothing in it should be something a participant couldn't also do within the one-hour build window. A demo that can't be reproduced in the room undercuts the hook rather than selling it.

A `README.md` alongside it will explain which primitives and assets it uses and why, so a facilitator can narrate it live without reverse-engineering the file first.
