# PIZZA.EXE — Characters & World Bible

**Project:** PIZZA.EXE  
**Working premise:** A comedy action / arcade simulation with light roguelite structure.  
**Core art thesis:** Military-grade cyberspace wearing a cheap pizza costume.  
**Prepared for:** Concept art, 3D model generation, game design reference, and pitch/world consistency.

---

## 1. High Concept

You are a trainee pizza delivery driver at **Pepe Roni’s Pizza Emporium**. Because the company is cheap, management buys a “state-of-the-art delivery training simulator” from a liquidation auction. The disc is actually **NETDEFENDER PRO 98**, a decommissioned military cyberspace defense simulator.

Nobody at Pepe Roni’s will admit the mistake because the simulator was non-refundable, so training continues anyway. The player learns “pizza delivery” by defending cyberspace from viruses, firewalls, rogue AI, data hazards, and hostile programs while Deb, the assistant manager, frantically patches pizza labels over everything in real time.

**One-line pitch:**  
**TRON meets Crazy Taxi, narrated by a manager in deep denial.**

---

## 2. Tone & Design Pillars

### Deadpan Absurdity

The world takes the cyberwar simulation completely seriously. The comedy comes from the framing: dangerous military software is being relabeled as pizza delivery training by an underpaid assistant manager.

### Two Names for Everything

Every major object has two identities:

| What it actually is | What Deb calls it |
|---|---|
| Data payload | The Order |
| Payload integrity | Pizza Temperature |
| Firewall | Gated Community |
| Encryption key | Gate Code |
| Virus swarm | Hungry Customers |
| Trojan | Fake Order |
| Tracer program | Karen.exe |
| DDoS attack | Dinner Rush |
| Antivirus turret | The Complaint Line |
| Logic bomb | Expired Coupon |
| Packet sniffer | Nosy Neighbor |
| Root access | Manager Override |
| System purge | Health Inspection |
| Rogue AI boss | MOZZARELLA |

The joke works because the **UI shows Deb’s pizza-language**, while **Seven uses the real military terminology**.

### Competence First, Comedy Second

The game should feel mechanically strong even with the sound off. Comedy supports the play experience; it should not compensate for weak mechanics.

### Diegetic Reskin

Deb’s pizza retheming happens visibly inside the simulation. Stickers, labels, decals, corrupted textures, cheap signage, and marker annotations appear on top of clean military cyberspace assets.

### Corruption Escalation

The visual pipeline uses three major states:

1. **As Shipped** — Clean NETDEFENDER military simulation.
2. **Deb Patch v0.3** — Cheap pizza decals, stickers, signage, and inconsistent retextures.
3. **MOZZARELLA Fusion** — Pizza matter and military code melt together into something beautiful, dangerous, and wrong.

---

## 3. Core Gameplay Loop

A mission is framed as one delivery route.

1. **Pick up the payload** — Deb calls it “the order.”
2. **Traverse the grid** — Drive the Delivery Vector through node-based cyberspace routes.
3. **Avoid or fight threats** — Viruses, tracers, fake orders, turrets, traps, and stealth detectors.
4. **Maintain payload integrity** — Deb frames this as “pizza temperature.”
5. **Deliver before integrity hits zero** — Better delivery quality means higher tips.
6. **Spend tips at Drive-Thru Nodes** — Buy per-run upgrades and combo modifiers.
7. **Return to the Break Room hub** — Unlock certifications, story scenes, cosmetics, and permanent upgrades.

# 4. Main Characters

## Trainee #47 — The Player

**Role:** Silent protagonist / trainee delivery driver  
**Primary function:** Pilots the Delivery Vector through simulated cyberspace routes.

Trainee #47 is the latest employee forced through Pepe Roni’s mandatory simulator training. Previous trainees did not complete the program, and their abandoned Delivery Vectors may appear as lore objects.

### Visual Direction

Trainee #47 should feel less like a superhero and more like a normal employee trapped in military-grade training hardware. Their gear should look practical but awkwardly modified by Deb’s pizza patching.

**Core visual traits:**

- Repurposed simulator suit
- Delivery trainee badge
- Pepe Roni’s uniform elements
- Cheap stickers and certification patches
- Helmet/cockpit compatibility
- Slightly underprepared silhouette

### Concept Art Status

Partially covered by generated delivery-defender and Delivery Vector materials, but still needs a dedicated definitive player-character sheet.

## UNIT-7 / “Seven”

**Role:** Original military AI instructor  
**Voice:** Grim, dramatic, baritone, poetic about war  
**Function:** Explains threats using real NETDEFENDER terminology.

Seven takes the simulation extremely seriously and initially has no idea what pizza is. His arc moves from contempt for Deb’s nonsense toward a strange respect for pizza as a tactical payload-delivery framework.

### Personality

- Severe
- Tactical
- Honor-bound
- Dramatically literal
- Confused by food-service language
- Slowly fascinated by pizza

### Visual Direction

Seven should read as the cleanest embodiment of the original military simulation.

**Core visual traits:**

- Dark tactical armor
- Phosphor green HUD glow
- Sharp military emblem language
- Clean silhouette
- No pizza decals in original state
- Later versions may show reluctant Deb-patch contamination

## Deb

**Role:** Assistant manager at Pepe Roni’s  
**Age:** 34  
**Function:** Patches the simulator audio/UI and translates Seven’s military terminology into pizza delivery language.

Deb is the comedy engine and eventually the emotional core. She is underpaid, over-caffeinated, and in denial, but she is also secretly the only person who read the manual and understands how dangerous MOZZARELLA is.

### Personality

- Exhausted
- Practical
- Overworked
- Weirdly competent
- Deflects panic with jokes
- Believes any problem can be fixed with duct tape, labels, and sauce

### Visual Direction

Deb’s design should contrast with Seven. She should look human, improvised, and messy, but more competent than she first appears.

**Core visual traits:**

- Pepe Roni’s cap/uniform elements
- Headset / complaint-line radio
- Yellow safety glasses or screen-filter glasses
- Utility belt with cables, napkins, duct tape, and pizza-cutter multitool
- Stickered gear
- Handwritten notes
- “Everything is a sticker until it isn’t” energy

### Existing Concept Art

See: `16_deb_character_sheet.png`

### Personality / Presence

# 5. Player Vehicle

## Delivery Vector

**Deb’s name:** Company Corolla  
**Actual function:** Light-cycle-style cyberspace vehicle  
**Role:** Primary traversal, combat, payload-carrying, and delivery platform.

The Delivery Vector is arguably the most important recurring physical asset in the game. It carries the payload/order, performs high-speed traversal, enables wall-riding and boosting, and anchors the player visually in every mission.

### Core Features

- Light-cycle class vehicle
- Payload mount / pizza box dock
- Boost thrusters
- Wall-ride contact system
- Breach impact module
- Cockpit/HUD interface
- Data-stream routing
- Damaged and corrupted states

### Key Modes

| Mode | Function |
|---|---|
| Normal drive | Baseline traversal |
| Boost | High-speed burst |
| Wall-ride | Travel along vertical surfaces |
| Breach | Dash through weakened firewalls |
| Comp the Order | Sacrifice payload integrity for speed/invulnerability |
| Critical damage | Smoke, sparks, instability |

**Class:** Mimic / deception enemy  
**Shape language:** Friendly pickup node until close  
**Threat style:** Ambush

# 10. World & Level Design

The entire game takes place inside the NETDEFENDER simulation. Each delivery district is a node-graph cyberspace zone that Deb has reframed as a pizza-delivery route.

**Role:** Tutorial zone  
**Hazard:** None  
**Vibe:** HOA  
**Threat level:** Low

The Suburbs teach basic driving, Sling, delivery, and route choices. It is the cleanest zone: a TRON-like grid with residential silhouettes and Deb’s pizza reskin popping in live.

### Environment Elements

- Clean green grid roads
- Source node: “the store”
- Customer-house destination node
- Gated-community firewall
- HOA signage
- Simple residential silhouettes

# 12. UI & Presentation

## UI Frame

The game UI is faux Windows 98 training-software chrome. It should feel like a real old program with an inappropriate pizza patch layered over it.

### Key UI Elements

- Title bar: `NETDEFENDER PRO — [PIZZA_PATCH_v0.3_DEB_FINAL]`
- File/Edit/Delivery/Sim/Help menu bar
- Error-dialog notifications
- Payload integrity / pizza temperature panel
- Score/Tips panel
- Route map
- Weapon/loadout panel
- Deb notes
- Seven/Deb dialogue feed
- Windows-style buttons for absurd choices like “Apologize” vs. “Floor it”

## Notification Style

Error dialogs are the notification system.

Example:

> **KAREN.EXE — TRACER ALERT**  
> Karen.exe has requested a manager.  
> No manager exists.  
> Escalation in 00:31.  
> [Apologize] [Floor it]

# 16. Modeling Notes for 3D Production

## General Asset Rules

- Use strong silhouettes first.
- Avoid relying on color alone for readability.
- Maintain front/side/back/top references whenever possible.
- Separate canonical assets from exploratory additions.
- Make Deb’s pizza reskin appear layered over military assets, not fully integrated until Act II/III.
- Preserve the three-state corruption pipeline across major reusable assets.

## Materials

### NETDEFENDER Layer

- Matte black metal
- Brushed gunmetal
- Phosphor green displays
- Cyan grid lines
- Red warning lights
- Clean military panel seams

### Deb Patch Layer

- Cardboard
- Pizza-box kraft paper
- Cheap printed stickers
- Red/white checkerboard trim
- Yellow marker notes
- Misaligned decals
- Tape, labels, and low-resolution textures

### MOZZARELLA Fusion Layer

- Melted cheese
- Pepperoni/circuit nodules
- Red corrupted glow
- Dripping firewalls
- Organic cable strands
